[컴퓨터구조] Performance

2022.09.08

어디에 중점을 두느냐에 따라 컴퓨터 성능이 달라진다

performance = 수행 시간의 역수

 CPU time에 집중한다

- Clock cycle

rising edge에서 data 전송. 다음 rising edge마다 state가 변한다

period: 주기, rate: period의 역수

수행 시간 = clock cycles * cycle time = clock cycles / rate

수행 시간이 가장 중요
