DEF CON 34 Satellite Hacking

2026.072026.08

개요

7월 한 달간 일본 도쿄의 GMO Ierae에서 팀과 함께 DEF CON 34 Aerospace Village에 전시할 위성 해킹 시나리오를 개발했습니다. 시나리오 기획과 공격 흐름 설계부터 구현, 테스트, 라스베이거스 현장 운영까지 전 과정에 참여했습니다.

폐쇄된 검증 환경의 위성 시뮬레이터와 미니 위성과 미니 안테나를 사용해, 방문자가 4개의 공격 시나리오를 직접 조작하며 배울 수 있는 체험형 전시입니다. 작년의 ‘보는 전시’에서 올해는 ‘만지는 전시’로 바뀌었습니다.

고민한 점

  • 정확성과 쉬움 사이의 균형
    공격이 어떻게 동작하는지뿐 아니라 왜 중요한지까지 참가자가 이해할 수 있도록 설계했습니다.
  • 시스템 관점
    개별 취약점을 넘어, 공격이 위성의 임무 전체에 어떤 영향을 미치는지에 초점을 맞췄습니다.
  • 협업
    서로 다른 문화와 배경을 가진 팀원들과 아이디어를 명확하게 전달하고 공통점을 찾아가며 함께 만들었습니다.

2025년, 첫 번째 DEF CON

2025년 8월 DEF CON 33에서 GMO Ierae는 아시아 기업으로는 처음으로 Aerospace Village에 부스를 열었고, 같은 해 CODE BLUE Tokyo에도 함께했습니다. 그때 복잡한 기술을 누구나 이해할 수 있게 전달하는 일의 중요성을 배웠고, 올해는 이미 있던 시나리오를 시연하는 데서 나아가 체험 전체를 처음부터 함께 만들었습니다.
